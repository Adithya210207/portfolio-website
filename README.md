# Adithya V | Portfolio Website

My personal portfolio: who I am, the projects I've built, and my certificates and credentials.

**Live:** https://adithya210207.github.io/

---

## What's inside

| Path | What it is |
|---|---|
| `index.html` · `css/style.css` · `js/app.js` | The website itself |
| `js/data.js` | All the content: projects, skills, certificates and journey |
| `img/` | Portrait, project screenshots and the link-preview card |
| `certificates/` | My certificates (PDF) and their thumbnails |
| `resume.html` · `resume.pdf` | My résumé and the page it is printed from |
| `tools/prerender.mjs` | Writes the JavaScript-drawn sections into `index.html` for search engines |
| `tools/share-card.html` | Source of the link-preview image `img/share.jpg` |
| `libs/` | GSAP, ScrollTrigger and Lenis (third-party) |
